Robot + 3D Camera Manual

An Intel RealSense D455 finds blue blocks on the work plate, including stacked blocks. A WLKATA Mirobot picks each one at the camera's position and drops it at the taught drop-off pose. Everything runs from one Python file, d455_pick_place.py, and calibrates itself.

How it works

Method

1 · Camera frames

Depth is aligned to the colour image, smoothed with RealSense spatial and temporal filters, and converted to millimetres. Close-range mode (disparity shift 50) lets it measure from about 20 to 70 cm.

2 · Table plane

A RANSAC plane fit on the depth points finds the plate. Every pixel then gets a height above the table in mm.

3 · Blue blocks

HSV colour range finds blue areas. Inside each one, the highest top face is kept, so touching piles are separated and the tallest block is taken first.

4 · Exact centre

Centre = middle of the rectangle around that top face, projected onto the top-face plane. Missing depth pixels no longer shift it. Before each pick, 8 frames are averaged and it is measured again.

5 · Wait for a still view

Frame-to-frame motion detection. It picks only after nothing has moved for 2 s and the block has stayed within 5 mm.

6 · Pick and place

The camera point is converted to robot X/Y/Z with the calibration, then G-code moves: above +40 mm → suction on → down to 2 mm below the top → lift → drop-off pose → release → park.

Automatic calibration

Calibration

The calibration tells the program where the camera is relative to the robot. It needs no clicking and no block.

  1. Plate must be empty. The program checks and refuses to start if it sees blocks.
  2. The robot moves the suction tool to 12 positions × 3 heights (tip at 150, 105 and 65 mm) over the plate.
  3. At each point the camera finds the white cap on the orange arm end in the colour image.
  4. solvePnPRansac computes the camera pose and ignores wrong detections (other white spots).
  5. The height is anchored to the taught pick pose (55, 40, 10, 0, −35, −45), where the tip is at Z 69.7 mm on top of a 32–33 mm block.
  6. The result is saved to d455_calib.json. The last run kept 23 of 34 points, average error 0.9 mm.
When to recalibrate

Whenever the camera is moved or bumped. Use the Recalibrate (camera moved) run option, or py -3.12 d455_pick_place.py autocal. If the file is missing, auto calibrates by itself first.

How to run

Operation
  1. Close WLKATA Studio, since only one program can use COM4.
  2. VS Code: open the Robot+3DCamera folder, choose Pick & Place - AUTO in Run and Debug, press F5. You can also open d455_pick_place.py and press ▶; with no arguments it runs AUTO.
  3. Put blocks on the plate and take your hand away. The window shows WAIT, then READY, then it picks.

Keys in the camera window

  • q stop: pump off, robot parks
  • a auto picking on / off
  • g pick the selected block now
  • n select the next block
  • c clear the done list (same-spot mode)

Box colours in the window

  • Green can be picked
  • Orange no depth on the block
  • Red out of robot reach
  • Grey already done (same-spot mode)

Safety
  • Keep a hand near the robot's power switch on the first run after any change.
  • Always stop with q so the pump turns off and the robot parks.
  • Remove all blocks before calibrating; the tool comes within ~3 cm of the plate.
  • After moving the camera, recalibrate before picking.
