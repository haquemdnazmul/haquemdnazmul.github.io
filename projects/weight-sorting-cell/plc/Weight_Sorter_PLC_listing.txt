//   * P00024 (L_GL) has 3 OUT coils - only the last one counts
//   * P00022 (L_RL) has 2 OUT coils - only the last one counts
//   * P00023 (L_YL) has 2 OUT coils - only the last one counts
//     Fix idea: build one condition per lamp (OR the cases together) and keep
//     a single OUT per output; use internal M relays for the intermediate cases.
//   * [028] SET R_STOP_ERR (M00501) when D_ERR_CODE = 0, i.e. when there is NO
//     error. Section 4 also sets it when D_ERR_CODE <> 0, so M00501 is always
//     ON. Was this meant to be RST?
//   * [080] At STEP_SORT = 8 the XCHGP swaps are not gated by SG_PLACE_DONE
//     (M00053), unlike the three other swap blocks, so the weight table is
//     swapped as soon as the place starts.
//   * [040] OUT M00001 / M00002 (HMI buttons B_SV_OFF / B_SV_CLR) inside the
//     factory-reset rung: the PLC forces these HMI bits OFF every scan when
//     factory reset is not pressed.
