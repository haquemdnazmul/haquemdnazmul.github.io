# Projects

Automation projects by **Md Nazmul Haque**. Portfolio: https://haquemdnazmul.github.io

| Project | What it is | Main tools |
|---|---|---|
| [Weight Sorting Cell](weight-sorting-cell/) | Picks blocks with a 3D camera and robot arm, weighs them on a load cell and sorts them into 9 slots by weight | LS XGB PLC, WLKATA Mirobot, Intel RealSense D455, Python, CIMON SCADA |
| [Motion-X Studio](motion-x-studio/) | Operator app for the weight sorting cell, with face login, a live 3D robot view and English/Korean screens | Python, Tkinter, OpenCV |
| [Conveyor Length Sorter](conveyor-length-sorter/) | Two conveyors and pneumatic pushers that sort blocks into three bins by length | LS XGB PLC, TOP HMI, Python |
| [6-Floor Elevator](six-floor-elevator/) | 6-floor elevator model with an AC motor, a pneumatic door and an HMI car panel | LS XGB PLC, TOP Design Studio |

These were team projects made during an automation training course in 2026.

## Opening the files

| Extension | Open with |
|---|---|
| `.xgwx` | LS Electric XG5000 (PLC program) |
| `.TDS` | TOP Design Studio (HMI screens) |
| `.xpd` | TOP Design Studio, older format (HMI screens) |
| `.py` | Python 3.12 |
