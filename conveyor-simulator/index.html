Conveyor Length Sorter Simulator

Built from the line's STEP assembly. Blocks stop at the measuring stopper, three BYD50 sensors read the length, and the PLC tracks each block in FIFO queues to outlet 1 (small), outlet 2 (medium) or the end box (large). Variable names follow the team's XG5000 parameter list.
